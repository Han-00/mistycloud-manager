# 流量分析

左侧「流量分析」专门查看长期趋势。主页面只有周期选择、每日平滑曲线、累计用量与日均，以及最多两条简要分析。曲线不显示圆点，悬浮或键盘左右移动可查看每日真实数值；缺失日期断开，单日记录不绘制虚构趋势。

选择7/30/90天或本月；选择「自定义日期」才展开日期输入，单次最多365天。「每日记录明细」与「统计说明」默认收起。导出明细为CSV，由桌面客户端的保存对话框选择位置。

套餐余额、续航、热力图和异常提醒继续在仪表盘查看。分析页面复用已有统计采样和状态更新，仅新增日汇总存储；日汇总保留365天，旧版小时桶仍保留约8天。升级时迁移尚存小时记录，已清理的历史无法恢复。

数据是本机管理过的账号合计，来自平台累计已用量的增量。首次查询和计数器回退只设基线；后续有效查询才确认新增消耗或零增量。无记录日期不当成零，今日不计入日均，前期记录不齐时不显示增长率。客户端停机后的差额记入恢复查询的时段，可能包含其他设备用量，不能代替平台账单。

CSV保存精确字节、采样次数、来源与状态，无记录用量留空，零增量为0，采用UTF-8 BOM方便Excel打开，不包含账号邮箱或密码。普通浏览器预览明确标注演示数据，真实历史及文件导出在桌面客户端中使用。
